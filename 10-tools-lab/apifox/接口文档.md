## GET 03 查询列表

GET /baseUrl/tasks

> 返回示例

> 200 Response

```json
[
  {
    "id": "string",
    "title": "string",
    "done": true
  }
]
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|Inline|

### 返回数据结构

状态码 **200**

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|» id|string|true|none||ID 编号|
|» title|string|true|none||none|
|» done|boolean|true|none||none|
